# Перша програма «Привіт, ліцею!»

| Файл | Навіщо |
|---|---|
| `main.cpp` | сама програма — тут пишемо код |
| `console_utf8.cpp` | вмикає українські літери в консолі Windows; не змінюйте його |
| `CMakeLists.txt` | проєкт для CLion |
| `pryvit.cbp` | проєкт для Code::Blocks |

## CLion

1. **File → Open** і виберіть цю теку.
2. Угорі праворуч має бути конфігурація `pryvit`.
3. **Run** або `Shift + F10`.

## Code::Blocks

1. **File → Open…** і виберіть файл `pryvit.cbp`.
2. **Build → Build and run** або `F9`.

Стандарт C++20 і попередження `-Wall -Wextra` у проєкті вже ввімкнено — налаштовувати нічого не потрібно.
