# Інформатика 10 · C++

Код прикладів, проєкти й зошити Google Colab до навчального посібника «Інформатика 10» (профільний рівень, мова програмування C++). Видавництво 97 Press.

## Зошити Colab

Відкрийте потрібний розділ і натисніть **Open in Colab**. Потрібен лише обліковий запис Google. Щоб зберегти свої зміни, зробіть копію: **Файл → Зберегти копію на Диску**.
