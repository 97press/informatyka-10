# Інформатика 10 · C++

Код прикладів, практичні роботи й зошити Google Colab до навчального посібника «Інформатика 10» (профільний рівень, мова програмування C++). Видавництво 97 Press.

## Як почати

**З Git (найзручніше).** У CLion: **File → New → Project from Version Control**, вставте адресу `https://github.com/97press/informatyka-10` і натисніть **Clone**. Оновити файли, коли з'являться нові розділи: **Git → Update Project**.

**Без Git.** [⬇ Завантажте архів](https://github.com/97press/informatyka-10/archive/refs/heads/main.zip), розпакуйте й відкрийте теку в CLion (**File → Open**).

Угорі праворуч у списку конфігурацій виберіть програму (наприклад, `p1_6` або `pr01_task2`) і натисніть **Run** (`Shift + F10`).

## Що всередині

| Тека | Для чого |
|---|---|
| `pryklady/` | приклади з посібника: запускайте й експериментуйте, змінюйте що завгодно |
| `praktychni/` | заготовки практичних робіт: пишіть розв'язок у `taskN.cpp` і перевіряйте на тестах |
| `colab/` | ті самі приклади в Google Colab — для роботи з телефона або без CLion |
| `common/` | службові файли курсу, не змінюйте їх |

## Практичні роботи й тести

1. Пишіть розв'язок прямо у файлі `taskN.cpp` замість `// TODO`.
2. Перевірте себе: у списку конфігурацій виберіть **All CTest** і натисніть **Run**. Зелений — тест пройдено, червоний — відкрийте його й подивіться, що очікувалося і що вивела ваша програма.
3. Тести тут — це приклади з умови. Учитель перевіряє ще й на інших, тому придумайте 2–3 власні вхідні дані.
4. Здаючи роботу, скопіюйте файл під своїм прізвищем латиницею: `task2_prizvyshche.cpp`.
5. Не змінюйте інші файли репозиторію: тоді оновлення завантажуються без конфліктів.

У Code::Blocks відкрийте файл `.cbp` у теці розділу або практичної: кожна програма там — окрема ціль збирання (**Build → Select target**). Тести в Code::Blocks не запускаються — перевіряйте приклади з умови вручну.
